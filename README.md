# LYDZ Site | 魔法数学

一个融合数学、魔法与科技视觉的原创游戏设计网站。项目包含品牌首页、九个可交互数学小游戏、统一规则档案、站内搜索与合作联系页面。

## 主要内容

- 全屏视频 Hero、M² 品牌 Logo 与星系游戏入口
- 派对社交、策略博弈、逻辑解谜三类游戏索引
- 四个精选游戏项目的大图展示与放大镜效果
- 九个独立游戏页面及统一红蓝科技视觉系统
- 集中展示全部玩法的规则详解页面
- 支持游戏与页面内容跳转的全站搜索
- 合作联系页面与双邮箱入口
- 魔法棒自定义光标、响应式布局和无障碍动效降级

## 技术栈

- Next.js 16
- React 19
- TypeScript
- vinext / Vite
- Cloudflare Worker 构建输出

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm ci
npm run dev
```

开发服务器默认可通过 `http://localhost:3000` 访问。

## 质量检查

```bash
npm run lint
npm test
```

`npm test` 会先执行生产构建，再运行服务器渲染与游戏规则回归测试。

## 页面路由

- `/`：魔法数学首页
- `/rules`：九个游戏的规则详解
- `/contact`：合作联系页面
- `/games/*`：九个独立游戏页面
